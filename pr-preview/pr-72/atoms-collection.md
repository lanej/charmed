content := "API gateway: healthy\nEvent stream: healthy\nJob workers: degraded"

### [Go usage](https://lanej.io/charmed/atoms-collection.html#collection%2ftable-code)

Imports: [`table`](https://pkg.go.dev/charm.land/bubbles/v2/table "charm.land/bubbles/v2/table") · [`collection`](https://pkg.go.dev/github.com/lanej/charmed/collection "github.com/lanej/charmed/collection") · [`theme`](https://pkg.go.dev/github.com/lanej/charmed/theme "github.com/lanej/charmed/theme")

```go
columns := []table.Column{
	{Title: "Service", Width: 20}, {Title: "State", Width: 12}, {Title: "Req/min", Width: 8},
}
rows := []table.Row{
	{"API gateway", "Healthy", "1,240"},
	{"Event stream", "Healthy", "860"},
	{"Job workers", "Degraded", "420"},
}
tableView := collection.NewTable(columns, rows, 48, 6, theme.New(theme.Dark))

return tableView.View()
```
