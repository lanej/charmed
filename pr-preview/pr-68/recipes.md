# Build around a task

Recipes connect individual components into a working view. Choose the outcome you need, inspect the native output, then follow the code and lifecycle contract before replacing the supplied observations with real application data.

## [Choose a task](https://lanej.io/charmed/recipes.html#choose-a-task)

| Task                              | Start here                                                                                   | What you will connect                                                           |
|-----------------------------------|----------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------|
| Monitor operational state         | [Operational dashboard](https://lanej.io/charmed/templates-pattern.html#template/operations) | Summary, primary evidence, scrolling and secondary inspection                   |
| Collect an environment name       | [Getting started](https://lanej.io/charmed/getting-started.html)                             | A text input, focus command and terminal resize messages                        |
| Plot measurements over time       | [Time series](https://lanej.io/charmed/atoms-chart.html#chart/timeseries)                    | Timestamped observations, shared axes and a cell allocation                     |
| Inspect an HTTP exchange          | [Correlated inspector](https://lanej.io/charmed/organisms-logs.html#pattern/log-inspector)   | Request timeline, independent payloads and related logs                         |
| Compare deployed versions         | [Fleet comparison](https://lanej.io/charmed/deployment.html)                                 | Weighted rates, host distributions and optional attention rules                 |
| Browse structured JSON            | [JSON viewer](https://lanej.io/charmed/json-viewer.html)                                     | Exact source bytes, container navigation and viewport state                     |
| Add application commands          | [Command palette](https://lanej.io/charmed/command-palette.html)                             | Search, availability, typed actions and focus restoration                       |
| Compose an application shell      | [Composition guide](https://lanej.io/charmed/examples.html)                                  | Header, tabs, active region and optional instructions                           |
| Structure sections inside columns | [Nested layouts](https://lanej.io/charmed/templates-layout.html)                             | Recursive Flex and Grid nodes, leaf allocations and explicit responsive recipes |
