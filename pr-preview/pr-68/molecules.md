## [Composing a single behavior](https://lanej.io/charmed/molecules.html#composing-a-single-behavior)

A molecule combines smaller pieces around one purpose. A labeled field adds help and validation to an input; a chart panel adds a title and optional legend to a plot. Each example links to the components it uses.

Keep layout allocations and native widget state with their owner. The [component reference](https://lanej.io/charmed/components.html) covers sizing, legends, diagrams and application chrome. Move to [organisms](https://lanej.io/charmed/organisms.html) when several related behaviors need coordination.
