Cohort measurements#

Three regional cohorts compare scalar temperature, summed energy, denominator-weighted yield and humidity with linked member inspection. Missing temperature remains absent.

Native preview#

Saved terminal output · truecolor reference
Example DemoNarrow256 colors16 colorsMonochromeDisconnected bands

Go usage#

Imports: time · cohort · layout · pattern · theme

start := time.Date(2026, 11, 12, 12, 0, 0, 0, time.UTC)
data := cohort.Data{
	Cohorts: []cohort.Cohort{{ID: "north", Label: "North", Short: "N"}, {ID: "south", Label: "South", Short: "S"}, {ID: "west", Label: "West", Short: "W"}},
	Metrics: []cohort.Metric{{ID: "temp", Label: "Temperature", Kind: cohort.Scalar, Unit: "C"}, {ID: "energy", Label: "Energy", Kind: cohort.Scalar, Unit: "kWh", Aggregation: cohort.Sum}, {ID: "yield", Label: "Yield"}, {ID: "humidity", Label: "Humidity", Kind: cohort.Scalar, Unit: "%"}},
	Windows: []cohort.Window{{Start: start, End: start.Add(time.Minute), Samples: []cohort.Sample{
		{MemberKey: cohort.MemberKey{CohortID: "north", MemberID: "sensor-1"}, Measurements: map[string]cohort.Measurement{"temp": {Value: -5}, "energy": {Value: 12}, "yield": {Numerator: 85, Denominator: 100}, "humidity": {Value: 30}}},
		{MemberKey: cohort.MemberKey{CohortID: "south", MemberID: "sensor-2"}, Measurements: map[string]cohort.Measurement{"temp": {Value: 12}, "energy": {Value: 18}, "yield": {Numerator: 90, Denominator: 100}, "humidity": {Value: 35}}},
		{MemberKey: cohort.MemberKey{CohortID: "west", MemberID: "sensor-3"}, Measurements: map[string]cohort.Measurement{"temp": {Value: 18}, "energy": {Value: 24}, "yield": {Numerator: 95, Denominator: 100}, "humidity": {Value: 40}}},
	}}},
}

comparison, err := pattern.NewCohortComparison(pattern.CohortComparisonOptions{Title: "Regional measurements", Data: data, ReferenceID: "north", Theme: theme.New(theme.Dark)})
if err != nil {
	return "", err
}

comparison.Resize(layout.Size{Width: 100, Height: 30})

return comparison.View(), nil

Deployment comparison#

Compare 2xx, 3xx, 4xx and 5xx by version identifier during a blue/green deployment. Reference/candidate roles, request-weighted histories, 1/2/3s host-spread bands and linked inspection use synthetic interval counts.

Native preview#

Saved terminal output · truecolor reference
Example DemoNarrow256 colors16 colorsMonochromeDisconnected bandsNo boundariesUniform regressionUnequal trafficInsufficient samples

Go usage#

Imports: time · cohort · layout · pattern · theme

start := time.Date(2026, 11, 8, 12, 0, 0, 0, time.UTC)
data := cohort.Data{
	Cohorts: []cohort.Cohort{
		{ID: "blue", Label: "Blue", Short: "blue"}, {ID: "green", Label: "Green", Short: "green"},
	},
	Metrics: []cohort.Metric{{ID: "5xx", Label: "Server errors"}},
	Windows: []cohort.Window{{Start: start, End: start.Add(time.Minute), Samples: []cohort.Sample{
		{MemberKey: cohort.MemberKey{CohortID: "blue", MemberID: "api-1"}, Requests: 2000, Counts: map[string]uint64{"5xx": 4}},
		{MemberKey: cohort.MemberKey{CohortID: "blue", MemberID: "api-2"}, Requests: 2000, Counts: map[string]uint64{"5xx": 6}},
		{MemberKey: cohort.MemberKey{CohortID: "green", MemberID: "api-3"}, Requests: 2000, Counts: map[string]uint64{"5xx": 12}},
		{MemberKey: cohort.MemberKey{CohortID: "green", MemberID: "api-4"}, Requests: 2000, Counts: map[string]uint64{"5xx": 18}},
	}}},
}

comparison, err := pattern.NewCohortComparison(pattern.CohortComparisonOptions{
	Title: "Deployment comparison", Data: data, ReferenceID: "blue", Theme: theme.New(theme.Dark),
	MinRequests: 1000, Sigma: 3, Variant: pattern.Bands,
})
if err != nil {
	return "", err
}

comparison.Resize(layout.Size{Width: 100, Height: 30})

return comparison.View(), nil
