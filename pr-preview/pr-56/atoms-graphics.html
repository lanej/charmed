Picture#

Portable glyph rendering of an embedded image; no external image service.

Saved terminal output · truecolor reference

Go usage#

Imports: image · color · chart · layout

gradient := image.NewRGBA(image.Rect(0, 0, 120, 60))

for y := range 60 {
	for x := range 120 {
		gradient.SetRGBA(x, y, color.RGBA{
			R: uint8(x * 2), G: uint8(70 + y*2), B: uint8(180 - x), A: 255,
		})
	}
}

picture, init := chart.NewPicture(gradient, layout.Size{Width: 40, Height: 10})
_ = init // Return this command from your Bubble Tea Init method.

return picture.View().Content

Updates, focus & sizing#

Render from application-owned values and pass one shared theme to related elements. These display helpers have no event loop or keyboard focus; the parent supplies updated values and recomputes the available terminal-cell allocation when the screen changes size.

go run ./examples/catalog chart/picture
