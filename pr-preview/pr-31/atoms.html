Using atoms#

Atoms expose a focused control or visual primitive with Charmed's shared theme. Start with the group that matches the information you need to display. Each component page includes terminal previews, color and width variants, and a Go usage example or a link to its implementation.

Compose related atoms into molecules. Read the component reference for input lifecycle, semantic status and other behavior contracts.
