Compose behavior as well as appearance

A complete screen owns one Go model and coordinates its child widgets. The service workbench links an input, table, time-series chart and details viewport. The deployment example coordinates host distributions, histories and inspection; read its telemetry contract and interpretation.

Ownership rules

Owner Responsibility
Theme Semantic colors, contrast, ASCII and motion policy
Layout parent Allocate rectangles in columns and rows, including borders
Focus scope Route keyboard input to the active child
Component Own its native widget state and return commands
Root runtime Own the terminal session and forward commands
Application Supply data and handle typed UI events

In the native service screen, Tab changes focus, arrows select rows and Ctrl+N advances background samples. Selection updates the chart and inspector together. Resize preserves selection; hidden regions leave the focus order.

In the native deployment screen, arrows choose hosts and windows, brackets choose a response class, 1/2/3 change displayed spread, and b switches between stacked and disconnected bands. These are terminal controls; the saved frames below do not execute them.

Switch between the deployment fixture's stacked and disconnected-band snapshots using the variant tabs, then inspect the corresponding Go implementation below the preview.

func NewDashboard(o DashboardOptions) *Dashboard {
	m := &Dashboard{theme: o.Theme, services: append([]Service(nil), o.Services...), live: o.Live, emit: o.Emit, showLegend: o.ShowLegend,
		focus: interaction.NewFocus("filter", "table", "chart", "details")}
	m.Filter = input.NewText(input.TextOptions{Placeholder: "Filter services…", Width: 80, Theme: o.Theme})
	if o.Theme.ASCII {
		m.Filter.Placeholder = "Filter services..."
	}
	m.Table = collection.NewTable(nil, nil, 35, 12, o.Theme)
	m.Details = collection.NewViewport("", 30, 8)
	m.Plot = chart.NewTimeSeries(nil, layout.Size{Width: 40, Height: 10}, o.Theme)
	m.Resize(layout.Size{Width: 120, Height: 34})
	m.applyFilter()
	return m
}

// Run with: go run ./examples/deployment
package main

import (
	"fmt"
	"os"

	tea "charm.land/bubbletea/v2"
	"github.com/lanej/charmed/examples/deployment/fixture"
	"github.com/lanej/charmed/layout"
	"github.com/lanej/charmed/pattern"
	"github.com/lanej/charmed/runtime"
	"github.com/lanej/charmed/theme"
)

func main() {
	data, err := fixture.Data("isolated-hosts")
	if err != nil {
		fmt.Fprintln(os.Stderr, err)
		os.Exit(1)
	}
	palette := theme.New(theme.Dark)
	screen, err := pattern.NewCohortComparison(pattern.CohortComparisonOptions{
		Title: "Deployment comparison", Scope: "method=blue/green / Synthetic HTTP responses / all routes",
		Data: data, Theme: palette, MinRequests: 1000, Sigma: 3, MetricTones: fixture.StatusTones(), Boundaries: fixture.Boundaries(), MetricSigns: fixture.StatusSigns(),
	})
	if err != nil {
		fmt.Fprintln(os.Stderr, err)
		os.Exit(1)
	}
	size := layout.Size{Width: 132, Height: 40}
	screen.Resize(size)
	root := &runtime.Root{Scene: screen, Size: size, Background: palette.Background, AltScreen: true}
	if _, err := tea.NewProgram(root).Run(); err != nil {
		fmt.Fprintln(os.Stderr, err)
		os.Exit(1)
	}
}
