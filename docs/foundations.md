# Foundations

Themes, cell geometry, focus and motion are shared across every component. Choose semantic roles rather than embedding color decisions in application widgets. Layout parents allocate rectangles in terminal columns and rows; focus scopes route keys to the active child.

The fixtures below show the default native frame. Saved variants retain narrow and monochrome configurations on the same night surface; these static exports retain native semantic color. Run with `--theme light`, `--columns 40` or `--ascii --profile none` to inspect those presentations in a terminal.
