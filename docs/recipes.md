# Build around a task

Recipes connect individual components into a working view. Choose the outcome you need, inspect the native output, then follow the code and lifecycle contract before replacing the supplied observations with real application data.

## Choose a task

| Task | Start here | What you will connect |
| --- | --- | --- |
| Collect an environment name | [Getting started](getting-started.html) | A text input, focus command and terminal resize messages |
| Plot measurements over time | [Time series](atoms-chart.html#chart/timeseries) | Timestamped observations, shared axes and a cell allocation |
| Inspect an HTTP exchange | [Correlated inspector](organisms-logs.html#pattern/log-inspector) | Request timeline, independent payloads and related logs |
| Compare deployed versions | [Fleet comparison](deployment.html) | Weighted rates, host distributions and optional attention rules |
| Browse structured JSON | [JSON viewer](json-viewer.html) | Exact source bytes, container navigation and viewport state |
| Add application commands | [Command palette](command-palette.html) | Search, availability, typed actions and focus restoration |
| Compose an application shell | [Composition guide](examples.html) | Header, tabs, active region and optional instructions |
